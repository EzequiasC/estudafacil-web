# EstudaFácil 📚

**EstudaFácil** é uma aplicação web responsiva desenvolvida como parte do Projeto de Extensão (UFMS Digital). O objetivo principal do sistema é auxiliar estudantes da modalidade de Educação a Distância (EAD) a organizar suas rotinas de estudos, gerenciar prazos e acompanhar pendências, contribuindo para a redução da evasão escolar.

## 🚀 Funcionalidades (Protótipo Inicial)
Nesta fase inicial de desenvolvimento, o projeto conta com as seguintes interfaces codificadas:
- **Tela de Autenticação/Boas-vindas:** Formulário de acesso ao sistema.
- **Dashboard Principal:** Painel de controle do aluno com resumo de matérias e menu de ações rápidas.
- **Design Responsivo:** Interface construída com a abordagem *mobile-first*, garantindo usabilidade em smartphones e computadores.

## 🛠️ Tecnologias Utilizadas
- **Back-end:** Python 3 e Framework Django
- **Front-end:** HTML5 e CSS3 puro (sem o uso de frameworks externos para garantir maior leveza)
- **Controle de Versão:** Git e GitHub
